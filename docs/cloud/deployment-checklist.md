# Deployment checklist

- [ ] Clinical, legal, privacy, security, and UAE deployment approval
- [ ] Region/residency confirmed for each service, backup, log, and key
- [ ] Managed identity and least privilege reviewed
- [ ] PostgreSQL RLS artifact adapted and reviewed
- [ ] Employer/HR/insurer firewall tested
- [ ] Append-only audit retention and tamper-chain operations tested
- [ ] Gate 2 and C-SSRS subset tests pass
- [ ] Emergency routing and local facility contacts clinically verified
- [ ] No real patient data in demo environments
- [ ] Rollback, incident, and break-glass runbooks approved
