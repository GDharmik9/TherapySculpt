# Frontend

`web-patient` provides patient screening, consent, safety-plan, calm-mind, and appointment routes. `web-clinician` provides triage, consultation, comorbidity, and Malaffi-sync placeholders. `web-admin` provides audit/fairness views. `mobile-patient` is an Expo shell.

Preserve logical RTL-friendly layouts and bilingual patient content. Crisis UI must remain accessible and expose 999 and Safety Plan Step 6. This scaffold is not production-ready.
